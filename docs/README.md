# Syntax Striker - 使用说明

## 🎮 游戏介绍

Syntax Striker 是一款命令驱动的太空射击游戏，结合了霓虹视觉效果和创新的游戏机制。玩家通过输入数字指令切换不同的攻击模式，在无限的游戏循环中击败越来越强的Boss。

## 📦 快速开始

### 安装与运行

1. **解压游戏文件**
   ```
   解压到任意目录
   cd syntax-striker
   ```

2. **安装依赖**
   ```bash
   npm install
   ```

3. **启动游戏**
   ```bash
   npm run dev
   ```

4. **打开浏览器**
   - 访问 `http://localhost:5173`
   - 游戏自动开始

## 游戏玩法

### 基本控制
- **鼠标移动** - 控制飞船位置
- **输入指令** - 在底部输入框中输入数字指令，按 Enter 执行

### 指令系统

| 指令 | 效果 | 颜色 |
|------|------|------|
| **1** | Fire 模式 - 对Boss持续伤害 | 橙色 |
| **2** | Ice 模式 - 减缓Boss子弹伤害 | 蓝色 |
| **3** | 双列子弹 | 黄色 |
| **4** | 激光束 (5秒) | 洋红 |
| **5** | 环形子弹散射 | 紫色 |
| **6** | 暂停/继续 | - |

### 游戏机制

**升级系统:**
- 初始: 火力等级 1 (慢速射击)
- 30分: Boss 1 出现 → 击败后升级到火力等级 2
- 100分: Boss 2 出现 → 击败后升级到火力等级 3 (最大)
- 之后每 100 分出现新 Boss，难度递增

**分数规则:**
- 击杀敌人: +100 分
- 子弹未命中: -10 分
- 被敌人撞击: -50 分
- 被Boss子弹击中: -15/7 (Ice模式)
- 击败Boss: +等级×100 分

**血量系统:**
- 初始血量: 100 HP
- 被敌人/Boss击中扣血
- 击败Boss后血量回满
- 血量归零 = 游戏结束

### Boss 特性

| 等级 | 血量 | 弹速 | 颜色 |
|------|------|------|------|
| Lv1 | 25 | 6 | 橙色 |
| Lv2 | 35 | 6 | 粉红 |
| Lv3+ | 45+ | 6 | 动态变色 |

## 技巧提示

1. **利用 Fire 模式** (指令1) 对Boss快速造成伤害
2. **Ice 模式** (指令2) 降低Boss子弹伤害，适合持久战
3. **双列子弹** (指令3) 提高命中率
4. **激光束** (指令4) 配合Fire模式快速击败Boss
5. **环形子弹** (指令5) 适合清理大量敌人
6. **及时暂停** (指令6) 规划下一步行动

## 故障排除

```bash
rm -rf node_modules package-lock.json
npm install
npm run dev
```
